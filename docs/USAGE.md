# 局部修改操作说明

1. 在主应用画布中选中一个或多个元素。
2. 右键，点击「删除」下面绿色的「AI 局部修改…」。
3. 在浮框输入指令，点击「执行」，或按 Ctrl/Cmd + Enter。输入框支持多行。
4. 等待结果。常见指令使用快速规则，其余交给主应用配置的模型；结果提示使用了哪条通道。

可尝试：左对齐、水平等距分布、等宽、变绿、变成正方形、向右移动 20、
删掉选中的、在旁边加一个同色圆角框。命令能力与细节以服务端规则和作用域校验为准。
新增、删除会改变结构；删除元素可能连带删除连接它的边。

## 显示编号

编号默认关闭。点击「显示编号」后，当前操作选区显示 ①、②、③；再次点击「隐藏编号」关闭。
编号只是临时屏幕标识，不会写入图形 XML。请求会携带编号到真实 cell ID 的映射。
可以用「将①的文字替换为入口」等描述指定元素。

编号按空间位置排列；当前实现会随视图刷新重新排序，移动元素、缩放后请以画面上的编号为准。
复杂的“参考①只改②”仍需结合规则匹配验证，不应假定所有含编号的句子都能精确执行。

## 关闭与恢复

- 点击 × 或在输入框按 Escape 关闭。
- 左键点击画布空白处清空选区，浮框与编号一起关闭。
- 改选其它元素后，重新右键打开新浮框，以新选区为修改范围。
- 不再提供额外的「复原上一次 AI 改动」按钮。draw.io 原生撤销仍保留；
  主应用同步 XML 时的撤销行为有历史限制，重要图形请先保存副本。

当前等待文案按耗时显示，并非服务端实时进度；耗时长不代表请求已失败。
更多边界及维护位置见 ARCHITECTURE.md。
